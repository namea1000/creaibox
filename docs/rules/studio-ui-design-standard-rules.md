# CreaiBox Studio UI Design Standard Rules (Vercel Style)

이 문서는 CreaiBox 스튜디오 내의 모든 메뉴와 대시보드를 디자인할 때 AI 에이전트와 개발자가 반드시 준수해야 하는 **표준 UI/UX 디자인 가이드**입니다.
이 가이드는 `domain-search` 메뉴 개편 과정에서 확립된 Vercel 및 Supabase 스타일의 쾌적하고 모던한 UI를 다른 모든 메뉴에 일관되게 적용하기 위해 작성되었습니다.

## 1. 뷰포트 레이아웃 (Viewport Layout)

- **와이드 표준 컨테이너**: 기존의 좁은 1024px, 1280px 박스형 레이아웃에서 벗어나, 기본적으로 **`max-w-[1680px]`** 규격을 사용하여 중앙 정렬하되 양옆으로 시원하게 넓은 뷰를 제공합니다.
- **패딩 최적화**: 좌우 여백을 넓혀 Vercel 화면처럼 양옆으로 꽉 차면서도 정갈하도록 **`px-5 sm:px-8 lg:px-12`** 규격의 쾌적한 패딩을 반드시 적용합니다.
- **Full-width 확장**: 데이터 테이블의 열이 많거나 캔버스 형태의 스튜디오(예: 웹사이트 빌더, 대시보드 그래프 등)인 경우 `max-w-full` 또는 `max-w-[1680px]`까지 상황에 맞게 꽉 채워 확장할 수 있습니다.

## 2. 기본 페이지 구조 (Vercel Settings Style)

스튜디오 내 서브 메뉴들은 다음과 같은 표준 구조를 따라야 합니다. (참조: Vercel의 Project Settings 화면)

1. **상단 타이틀 & 설명 (Header)**:
   - 좌측 정렬된 큼직하고 명확한 제목 (`text-xl` ~ `text-2xl` font-bold).
   - 바로 아래에 해당 메뉴의 목적과 기능을 설명하는 서브 텍스트 (`text-sm text-slate-500`).
2. **언더라인 탭 네비게이션 (Sub-Tabs)**:
   - 한 페이지에 너무 많은 UI를 때려 넣지 않고, 기능별로 독립된 디렉토리(Sub-pages)로 분리합니다.
   - 각 페이지를 이동할 때 상단에 공통으로 나타나는 **Vercel 스타일의 언더라인 탭 네비게이션**(예: `DomainTabHeader.tsx`)을 배치합니다.
   - 활성화된 탭은 하단에 굵은 검은색(다크모드 시 흰색) 밑줄과 함께 진한 글씨체로 표시하고, 비활성화 탭은 옅은 회색으로 둡니다.
3. **본문 콘텐츠 박스 (Content Box)**:
   - 탭 메뉴 아래에 1~2개의 넓고 쾌적한 설정 박스 혹은 데이터 테이블 카드가 위치합니다.

## 3. 컬러 시스템: 완벽한 모노톤 (Black & White)

라이트 모드와 다크 모드에서 디자인이 어색해지는 현상을 원천 차단하기 위해 **테마/포인트 컬러의 남용을 금지**하고 철저한 모노톤(Monotone)을 지향합니다.

- **글자 컬러**: 주요 텍스트는 블랙(`text-slate-900`) / 화이트(`text-white`), 보조 텍스트는 짙은 회색(`text-slate-500`)만을 사용합니다.
- **버튼**: 기본 액션 버튼은 솔리드 블랙(`bg-black text-white`) / 솔리드 화이트(`bg-white text-black`)로 구성합니다.
- **에러 및 성공 피드백**: 아주 제한적으로만 에러/위험은 Rose(`text-rose-600`), 성공/안전은 Emerald(`text-emerald-500`), 링크/정보는 Blue(`text-blue-500`) 컬러를 사용하며 면적(배경색)을 넓게 칠하지 않고 주로 아이콘이나 텍스트 컬러에만 포인트로 사용합니다.

## 4. 박스 및 폼 UI 규격 (Cards & Forms)

- **배경색 억제**: 카드(Box) 내부에 또 다른 짙은 배경색을 넣는 것을 금지합니다. 배경색은 완전히 빼거나(투명) 아주 옅은 색상(`bg-slate-50/50`, 다크모드 `bg-zinc-900/30`)만 사용합니다.
- **테두리와 모서리**: `border border-slate-200 dark:border-zinc-800`를 사용해 명확하고 얇은 구분선을 제공하고, 모서리는 부드러운 `rounded-lg` 또는 `rounded-xl`을 사용합니다.
- **그림자 (Shadow)**: 입체감을 주기 위한 과도한 그림자는 배제하고, 가장 얕은 `shadow-sm` 또는 `shadow-xs` 규격만 사용하여 플랫(Flat)하고 모던한 느낌을 줍니다.

## 5. 데이터 테이블 규격 (Tables)

- 데이터의 가독성을 극대화하기 위해 테이블 셀(td, th) 간의 세로줄 구분선(Vertical border)을 완전히 제거하고, 가로줄 구분선(Horizontal `divide-y`)만 사용합니다.
- 테이블 헤더(th)는 옅은 회색 배경(`bg-slate-50/40`)에 작고 굵은 폰트(`text-xs font-semibold`)를 사용합니다.
- 본문 로우(Row)는 마우스 오버 시 미세한 배경색 변화(`hover:bg-slate-50/50 transition-colors`)를 주어 상호작용 피드백을 제공합니다.

---
**에이전트 행동 강령 (Agent Directive):**
앞으로 CreaiBox 스튜디오 내의 어떤 메뉴(글쓰기 스튜디오, 리서치 스튜디오 등)를 신규 개발하거나 디자인 리팩토링을 지시받을 경우, **무조건 본 디자인 표준 룰 문서를 최우선적으로 참고**하여 1680px 와이드 + 모노톤 기반의 Vercel 스타일로 코드를 작성해야 합니다.
