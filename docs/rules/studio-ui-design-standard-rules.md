# CreaiBox Studio UI Design Standard Rules (Vercel Style)

이 문서는 CreaiBox 스튜디오 내의 모든 메뉴와 대시보드를 디자인할 때 AI 에이전트와 개발자가 반드시 준수해야 하는 **표준 UI/UX 디자인 가이드**입니다.
이 가이드는 `domain-search` 메뉴 개편 과정에서 확립된 Vercel 및 Supabase 스타일의 쾌적하고 모던한 UI를 다른 모든 메뉴에 일관되게 적용하기 위해 작성되었습니다.

## 1. 뷰포트 레이아웃 (Viewport Layout)

- **와이드 표준 컨테이너**: 기존의 좁은 1024px, 1280px 박스형 레이아웃에서 벗어나, 기본적으로 **`max-w-[1680px]`** 규격을 사용하여 중앙 정렬하되 양옆으로 시원하게 넓은 뷰를 제공합니다.
- **패딩 최적화**: 좌우 여백을 넓혀 Vercel 화면처럼 양옆으로 꽉 차면서도 정갈하도록 **`px-5 sm:px-8 lg:px-12`** 규격의 쾌적한 패딩을 반드시 적용합니다.
- **Full-width 확장**: 데이터 테이블의 열이 많거나 캔버스 형태의 스튜디오(예: 웹사이트 빌더, 대시보드 그래프 등)인 경우 `max-w-full` 또는 `max-w-[1680px]`까지 상황에 맞게 꽉 채워 확장할 수 있습니다.

## 2. 기본 페이지 구조 (Vercel Settings Style)

스튜디오 내 서브 메뉴들은 다음과 같은 표준 구조를 따라야 합니다. (참조: Vercel의 Project Settings 화면)

1. **상단 타이틀 & 설명 (Header)**:
   - 좌측 정렬된 큼직하고 명확한 제목 (`text-xl` ~ `text-2xl` font-bold).
   - 바로 아래에 해당 메뉴의 목적과 기능을 설명하는 서브 텍스트 (`text-sm text-slate-500`).
2. **언더라인 탭 네비게이션 (Sub-Tabs)**:
   - 한 페이지에 너무 많은 UI를 때려 넣지 않고, 기능별로 독립된 디렉토리(Sub-pages)로 분리합니다.
   - 각 페이지를 이동할 때 상단에 공통으로 나타나는 **Vercel 스타일의 언더라인 탭 네비게이션**(예: `DomainTabHeader.tsx`)을 배치합니다.
   - 활성화된 탭은 하단에 굵은 검은색(다크모드 시 흰색) 밑줄과 함께 진한 글씨체로 표시하고, 비활성화 탭은 옅은 회색으로 둡니다.
3. **본문 콘텐츠 박스 (Content Box)**:
   - 탭 메뉴 아래에 1~2개의 넓고 쾌적한 설정 박스 혹은 데이터 테이블 카드가 위치합니다.

## 3. 컬러 시스템: 완벽한 모노톤 (Black & White)

라이트 모드와 다크 모드에서 디자인이 어색해지는 현상을 원천 차단하기 위해 **테마/포인트 컬러의 남용을 금지**하고 철저한 모노톤(Monotone)을 지향합니다.

- **글자 컬러**: 주요 텍스트는 블랙(`text-slate-900`) / 화이트(`text-white`), 보조 텍스트는 짙은 회색(`text-slate-500`)만을 사용합니다.
- **버튼**: 기본 액션 버튼은 솔리드 블랙(`bg-black text-white`) / 솔리드 화이트(`bg-white text-black`)로 구성합니다.
- **에러 및 성공 피드백**: 아주 제한적으로만 에러/위험은 Rose(`text-rose-600`), 성공/안전은 Emerald(`text-emerald-500`), 링크/정보는 Blue(`text-blue-500`) 컬러를 사용하며 면적(배경색)을 넓게 칠하지 않고 주로 아이콘이나 텍스트 컬러에만 포인트로 사용합니다.

## 4. 박스 및 폼 UI 규격 (Settings 스타일)

- **그룹화된 보더 박스**: 각 설정 섹션은 화면 전체를 무의미하게 채우지 않고, 명확하고 얇은 외곽선 박스(`border border-zinc-200 dark:border-zinc-800 rounded-lg`)로 컨텐츠를 그룹핑합니다.
- **배경색 억제**: 카드(Box) 내부에 또 다른 짙은 배경색을 넣는 것을 금지하며 투명하거나 극도로 옅은 색상만 유지합니다. 그림자는 배제하거나 가장 얕은 `shadow-sm`만 사용합니다.
- **타이틀과 설명 구조**: 설정 박스 내부 상단이나 좌측에 해당 섹션의 제목(`text-sm font-medium`)과 서브 설명 텍스트(`text-xs text-slate-500`)를 일관성 있게 배치합니다.
- **인풋 및 폼 요소**: 라벨은 작고 견고하게(`text-xs`~`text-sm font-medium`), 인풋 필드는 얇은 테두리와 쾌적한 안쪽 여백을 가지며, 포커스 시 명확한 테두리 하이라이트 피드백을 제공합니다.
- **액션 버튼 배치**: 저장/변경 등의 액션 버튼은 폼 최하단 우측 등 명확한 위치에 두며, 긍정/완료 액션에는 테마 포인트 컬러(예: 에메랄드/그린 계열)를 제한적으로 활용할 수 있습니다.

## 5. 데이터 테이블 규격 (Deals 표 스타일)

- **플랫(Flat) 테이블 디자인**: 테이블 외곽을 무거운 색상이나 두꺼운 테두리로 감싸지 않고, 배경에 자연스럽게 녹아드는 매우 플랫하고 미니멀한 디자인을 지향합니다.
- **미니멀 헤더 (Header)**: 테이블 헤더(th)에 눈에 띄는 배경색을 넣지 않고, 매우 작고 옅은 폰트(`text-[10px]` 또는 `text-xs text-slate-500 uppercase tracking-wider font-semibold`)를 사용하여 본문 데이터를 더 돋보이게 합니다.
- **세로줄 제거 및 얇은 가로줄**: 셀 간의 세로선(Vertical border)을 100% 제거합니다. 가로선 또한 매우 얇고 옅은 색상(`border-b border-zinc-100 dark:border-zinc-800/50`)만 사용하여 행(Row)을 구분합니다.
- **로우(Row) 호버 피드백**: 각 행에 마우스 오버 시 아주 미세한 배경색 변화(`hover:bg-zinc-50 dark:hover:bg-zinc-800/30 transition-colors`)를 주어 상호작용 피드백을 제공합니다.
- **상태 배지 (Status Badges)**: 성공/대기/실패 등 상태를 나타내는 값은, 반투명한 배경과 원색 텍스트의 조합(예: `bg-emerald-500/10 text-emerald-500`)으로 이루어진 작은 라운드 칩/배지 형태로 표현하여 세련된 포인트를 줍니다.
- **페이징 (Pagination)**: 페이징 컨트롤은 표의 우측 하단에 미니멀하게 배치하며, 활성화된 현재 페이지 번호에만 포인트 컬러를 줍니다.

## 6. 대시보드 및 KPI 메트릭 규격 (Overview & Reports)

- **빅 타이포그래피 (Big Typography)**: 핵심 지표(예: 총 수익, 전환율, 수치 등)는 글자 크기를 대폭 키워(`text-3xl`~`text-4xl font-bold`) 직관적으로 시선을 사로잡게 디자인합니다.
- **얇고 세련된 그래프/차트**: 차트의 선(Line)은 최대한 얇고 날카롭게 처리하며, 다크 모드 환경에서는 라인 아래쪽으로 투명도가 들어간 은은한 그라데이션 채우기(빛 번짐 효과)를 적용해 깊이감을 줍니다.
- **슬림 프로그레스 바 (Progress Bars)**: 목표 달성률이나 상태를 나타내는 바(Bar)는 두껍지 않은 아주 얇고 둥근 모서리(`h-1.5 rounded-full`)로 구성하며, 모노톤 배경 위에서 돋보이도록 네온 포인트 컬러(그린, 블루, 오렌지 등)를 가미합니다.
- **미니멀 트렌드 인디케이터**: 상승/하락 증감률(예: `+12.5%`, `-5%`)은 작은 화살표 아이콘과 함께 `text-xs` 사이즈의 명확한 상태 색상(`text-emerald-500` 또는 `text-rose-500`)으로 주 수치 우측에 밀착 배치합니다.

## 7. 데이터 카드 그리드 규격 (Customers 스타일)

- **독립된 얇은 외곽선 카드 배열**: 고객사, 리포트, 프로젝트 목록 등을 나열할 때는 2단 또는 3단 그리드 구조(`grid-cols-1 md:grid-cols-2 xl:grid-cols-3`)로 얇은 테두리를 가진 카드 컴포넌트를 사용합니다.
- **이니셜 아바타 포인트**: 썸네일 이미지가 없는 항목은, 다채로운 포인트 컬러 배경이나 어두운 바탕의 원형 이니셜 아바타(`w-10 h-10 rounded-full flex items-center justify-center`)를 상단 좌측에 배치하여 지루함을 덜어냅니다.
- **메타데이터 아이콘 정렬**: 주소, 이메일, 전화번호 등 부가 정보는 아주 작은 아이콘(Lucide 아이콘 등)과 함께 `text-xs text-slate-500`를 적용하여 촘촘하고 정돈되게 나열합니다.
- **분리된 하단 액션바**: 카드 내부 최하단에는 얇은 가로선(`border-t border-zinc-100 dark:border-zinc-800/50`)으로 영역을 구분한 뒤, 가벼운 텍스트/아이콘 버튼(예: `Schedule`, `Email` 등)을 수평으로 나열하여 편의성을 높입니다.

---
**에이전트 행동 강령 (Agent Directive):**
앞으로 CreaiBox 스튜디오 내의 어떤 메뉴(글쓰기 스튜디오, 리서치 스튜디오 등)를 신규 개발하거나 디자인 리팩토링을 지시받을 경우, **무조건 본 디자인 표준 룰 문서를 최우선적으로 참고**하여 1680px 와이드 + 모노톤 기반의 Vercel 스타일로 코드를 작성해야 합니다.
