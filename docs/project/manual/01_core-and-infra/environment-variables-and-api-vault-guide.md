이 문서는 CreaiBox 프로젝트의 로컬 환경변수(`.env.local`), 실서버 Vercel 환경변수, 그리고 최고 보안 수준의 `API_VAULT_ENCRYPTION_KEY`가 각각 어떤 역할을 하며 어떻게 상호작용하는지 명확하게 이해하기 위해 작성되었습니다.

---

## 1. `.env.local` 파일의 역할 (내 컴퓨터 전용 비밀 금고)

`.env.local` 파일은 프로젝트를 **로컬 환경(내 컴퓨터)**에서 실행하고 테스트하는 데 필요한 모든 비밀번호와 API 키를 보관하는 곳입니다.

- **절대 외부 유출 금지**: 데이터베이스 비밀번호, 외부 연동 API 키(유튜브, 결제 시스템 등) 등 핵심 보안 정보가 담겨 있습니다.
- **Git 자동 제외**: 깃허브(GitHub) 같은 저장소에 코드를 올릴 때, 해킹 방지를 위해 이 파일은 업로드 목록에서 자동으로 제외(`.gitignore`)됩니다.
- **오직 로컬용**: 즉, 이 파일에 아무리 많은 키를 추가하더라도 **실서버(Vercel)에는 절대 자동으로 넘어가지 않습니다.**

---

## 2. Vercel 실서버 환경변수 (프로덕션 필수 동기화)

로컬에서 완벽하게 작동하던 기능(예: 결제 처리, 크론 자동화 등)이 실서버에 올렸을 때만 에러가 난다면 99%는 **Vercel 환경변수 누락** 때문입니다.

- **수동 동기화 필수**: `.env.local`에 새로운 키를 추가했다면, 반드시 Vercel 대시보드 사이트의 **[Settings > Environment Variables]** 메뉴로 이동하여 **똑같은 이름과 똑같은 값을 수동으로 복사+붙여넣기** 해주어야 합니다.
- **재배포(Redeploy) 필수**: Vercel에 키를 추가한 직후에는 반드시 **Deployments 탭에서 [Redeploy]**를 실행해야만 서버가 껐다 켜지면서 새로운 키를 인식하고 작동을 시작합니다.

---

## 3. `API_VAULT_ENCRYPTION_KEY` 란 무엇인가?

CreaiBox는 강력한 보안을 위해 외부 API 키(유튜브, AI 엔진 등)를 소스 코드에 하드코딩하지 않고, **Supabase 데이터베이스(`admin_api_vault` 테이블)에 암호화하여 보관**합니다.

- **마스터 해독 열쇠**: DB에 암호화되어 저장된 외계어 같은 API 키를 원본으로 풀 때 사용하는 **'마스터 암호 해독 열쇠'**가 바로 `API_VAULT_ENCRYPTION_KEY` 입니다.
- **생성 원리**: 암호학적으로 절대 뚫릴 수 없는 32바이트 길이의 강력한 무작위 난수(Base64 인코딩)로 생성되어 발급되었습니다.
- **패딩 문자(`=`) 필수**: 키 맨 끝에 있는 `=` 기호는 오타가 아니라 Base64 암호화 규격의 '패딩(Padding)' 문자입니다. 이 기호가 하나라도 빠지면 32바이트 규격이 깨져서 해독이 100% 실패하므로, **무조건 `=`까지 포함한 전체를 복사해서 Vercel에 넣어야 합니다.**

---

## 4. 환경변수의 공개 범위 및 보안 규칙 (`NEXT_PUBLIC_` vs 일반 키)

Vercel 대시보드 환경변수에 입력된 키들은 기본적으로 Vercel 암호화 서버에 안전하게 보관됩니다. 그러나 **키 이름의 접두사(Prefix)**에 따라 대중(브라우저)에게 노출되는지 여부가 결정됩니다.

### 🛡️ 서버 전용 비밀 키 (이름이 `NEXT_PUBLIC_`으로 시작하지 않음)
- **예시**: `API_VAULT_ENCRYPTION_KEY`, `YOUTUBE_API_KEY`, `PORTONE_API_SECRET` 등
- **특징**: 백엔드(서버 뒷단)에서만 사용됩니다. 외부 접속자나 브라우저 소스 코드 검사로 절대 찾아낼 수 없는 **100% 철통 보안 키**입니다.

### 📢 브라우저 공개용 키 (이름이 `NEXT_PUBLIC_`으로 시작함)
- **예시**: `NEXT_PUBLIC_PAGESPEED_API_KEY`, `NEXT_PUBLIC_PORTONE_STORE_ID` 등
- **특징**: 웹사이트 접속자의 브라우저(프론트엔드 자바스크립트)에서 직접 결제창을 띄우거나 API를 호출해야 할 때 사용됩니다.
- **보안성**: 브라우저 소스 코드에 노출되지만, 서비스 제공업체(포트원, 구글 등)에서 읽기 전용으로 제한하거나 특정 도메인(creaibox.com)에서만 작동하도록 안전장치가 걸려있는 **공개 전용 키**이므로 안심하고 사용해도 됩니다. (Vercel에서 `Mark as Safe`로 승인 가능)

## 5. 자주 발생하는 실무 에러 케이스 (Troubleshooting)

### Q. 로컬에서는 데이터 수집(크론)이 잘 되는데, 오전 6시 실서버 수집은 왜 실패했나요?
**원인**: Vercel 실서버 환경변수에 `API_VAULT_ENCRYPTION_KEY`가 누락되었기 때문입니다.
**과정**:
1. 실서버 크론이 구동되어 DB에서 유튜브 API 키를 꺼내옴.
2. 하지만 해독 열쇠(`API_VAULT_ENCRYPTION_KEY`)가 Vercel에 없어서 암호를 풀지 못함.
3. API 키 획득에 실패하여 "가용한 YouTube API 키가 존재하지 않습니다" 에러를 내뿜고 수집 로직이 강제 종료됨.

### 💡 실무 행동 지침 (Action Item)
앞으로 새로운 API나 외부 결제 모듈(예: PortOne V2)을 연동할 때, 로컬 `.env.local`에 키를 적는 것으로 끝내지 마십시오.
작업이 끝나는 즉시 **Vercel 환경변수 탭을 열어 동일하게 키를 삽입하고 [Redeploy] 버튼을 누르는 것까지가 "하나의 개발 완료 프로세스"** 임을 반드시 기억해야 합니다.
