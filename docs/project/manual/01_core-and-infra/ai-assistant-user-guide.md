## 1. 개요 및 목적 (WHY)
AI Assistant 허브는 CreaiBox 내 모든 스튜디오(글쓰기, 자료분석, 음악, 디자인, 영상)에서 작업자의 현재 맥락(Context)을 실시간으로 파악하여 최적의 AI 에이전트를 자동 연결해 주는 중앙 지능형 비서입니다.

* **타겟 독자**: 서비스 운영팀, 실무 개발자, 기획자
* **적용 대상**: 전 스튜디오 우측 상단 플로팅 AI 어시스턴트 위젯

## 2. HOW-TO: 실무 조작 가이드

### 2.1. 컨텍스트 자동 주입 기능 활용
1. **Writing Studio에서 작업 중일 때**:
   - 작성 중인 원고의 제목, 본문, 메인 키워드가 어시스턴트에 실시간 동기화됩니다.
   - "이 글의 결론을 200자 내외로 요약해 줘" 또는 "SEO 점수를 높일 소제목 3개 추천해 줘"라고 질문하면 본문을 직접 복사해 넣을 필요 없이 즉시 맞춤형 답변을 생성합니다.
2. **Music Studio에서 작업 중일 때**:
   - 현재 작업 중인 가사와 장르, Suno 프롬프트가 주입되어, "현재 가사의 브릿지(Bridge) 파트를 감성적인 느낌으로 추가해 줘"와 같은 맥락형 작업이 가능합니다.

### 2.2. 폴더 및 대화 이력 관리
- 좌측 사이드 패널에서 프로젝트/주제별로 **폴더를 생성**하여 대화 내역을 분류 보관할 수 있습니다.
- 대화 내역은 Supabase DB(`ai_assistant_conversations`)에 자동 동기화되어 새로고침 후에도 유지됩니다.

## 3. 실무 개발자 및 운영자 필수 참고 (금지 패턴 & Anti-Patterns)

> [!WARNING]
> **AI Assistant 개발/운영 시 절대 금지 사항**

1. **사용자 컨텍스트 전체 무제한 주입 금지 (토큰 폭탄 방지)**
   - 대용량 첨부파일이나 수만 자의 전체 문서를 프롬프트에 통째로 밀어 넣지 마세요.
   - 핵심 요약본 및 관련 섹션(최대 4,000 토큰 이내)으로 청킹(Chunking)하여 주입해야 API 비용과 속도를 최적화할 수 있습니다.

2. **단일 거대 프롬프트 의존 금지 (멀티 에이전트 분기 표준)**
   - 하나의 범용 프롬프트로 글쓰기/작곡/SEO/코딩을 모두 처리하려 하지 마세요.
   - Intent Classifier를 통해 `writing_agent`, `music_agent`, `seo_agent` 등 전용 전문 에이전트로 분기 호출해야 품질이 극대화됩니다.

## 4. FAQ
**Q. 등급별(Free, Pro, Business) 사용량 제한은 어디서 관리하나요?**
A. Supabase의 `ai_assistant_plan_limits` 테이블에서 플랜별 최대 대화 수, 문자 수 한도, 멀티 에이전트 사용 권한을 실시간으로 제어할 수 있습니다.
