## 1. 기능 개요
이관해 온 웹사이트 중 디자인이 훌륭한 사이트를 **"나만의 템플릿(My Custom Template)"**으로 원클릭 보관하고, 언제든 다른 고객사나 브랜드의 홈페이지를 만들 때 1초 만에 그대로 적용하는 기능입니다.

---

## 2. 사용 방법 (HOW-TO)

### 2.1. 이관 히스토리에서 템플릿으로 보관하기
1. `스튜디오 홈` ➔ `AI 웹사이트 빌더` ➔ **`기존 홈페이지 이관`** (`/studio/custom-client-site/migration`)으로 이동합니다.
2. 하단의 **"나의 홈페이지 AI 이관 히스토리"** 목록에서 마음에 드는 사이트 카드를 찾습니다.
3. 우측의 **`[ 📦 템플릿으로 보관 ]`** 버튼을 클릭합니다.
4. 원하는 템플릿 이름을 입력하고 확인을 누르면, 해당 디자인 뼈대가 나만의 템플릿 보관함에 안전하게 저장됩니다.

### 2.2. 템플릿 쇼핑에서 새 사이트로 1초 배포하기
1. `스튜디오 홈` ➔ `AI 웹사이트 빌더` ➔ **`템플릿 쇼핑 & 1초 구축`** (`/studio/custom-client-site/marketplace`)으로 이동합니다.
2. 상단 카테고리에서 **`[ 📦 나만의 템플릿 ]`** 탭을 선택합니다.
3. 등록해 둔 템플릿의 **`[ 🚀 이 템플릿으로 1초 구축 ]`** 버튼을 누르고 새로운 회사 이름과 서브도메인을 입력하면 완료됩니다!
