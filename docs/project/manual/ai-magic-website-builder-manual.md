# AI 홈페이지 매직 빌더 가이드 및 향후 고도화 전략

본 문서는 CreaiBox 커스텀 클라이언트 스튜디오 내 **'AI 홈페이지 매직 빌더 🪄'** 기능의 상세 구현 내역, 서비스 사용 매뉴얼, 그리고 향후 크롤링 한계를 극복하기 위한 Apify 활용 방안을 기록한 실전 운용 매뉴얼입니다.

---

## 1. 개요 및 기획 의도

기존의 '홈페이지 이관' 기능이 타사 솔루션으로 만들어진 웹사이트의 HTML 구조를 완벽하게 "복제(Clone)"하는 데 목적을 두었다면, **'AI 홈페이지 매직 빌더' 기능은 빈약한 정보와 참조 자료들로부터 완전히 새로운 비즈니스 웹사이트를 "창작(Zero-to-One Synthesis)"**하는 데 목적이 있습니다.

- 인스타그램, 틱톡, 네이버 블로그 등 기존에 운영 중인 여러 채널 주소를 최대 3개까지 입력할 수 있습니다.
- 추가로 텍스트나 PDF와 같은 명시적인 참조 자료를 첨부하여 AI에게 제공할 수 있습니다.
- AI(Gemini 3.5 Flash Lite)가 해당 채널들의 텍스트와 첨부 자료의 맥락을 심층 분석하여, 랜딩 페이지 형태의 완벽한 비즈니스 홈페이지(Hero 카피, About 설명, 갤러리 레이아웃 등)를 즉석에서 기획하고 퍼블리싱합니다.

---

## 2. 사용 매뉴얼 (How to Use)

### Step 1. 다중 참조 주소 입력 (고정 3개)

1. **[스튜디오] > [커스텀 클라이언트 사이트] > [AI 홈페이지 매직 빌더 🪄]** 메뉴로 진입합니다.
2. 운영 중인 주력 SNS 플랫폼(네이버 블로그, 네이버 스마트 플레이스, 인스타그램 등) 프로필 주소나 주요 포스팅 주소를 최대 3개까지 입력합니다.
3. 여러 개의 주소를 입력하면 AI가 모든 주소의 정보를 취합하여 종합적으로 분석합니다.

### Step 2. 참조 자료 첨부 (선택 사항)

별도의 선택이 없으면 AI가 기존 문맥만으로 유추하는 **기본(자율 창작) 모드**로 동작합니다.
1. **텍스트 입력**: 버튼을 클릭(토글)하여, 새 홈페이지에 반드시 들어가야 할 주요 키워드나 인사말, 핵심 내용 등을 텍스트 박스에 자유롭게 입력합니다.
2. **PDF 파일 업로드**: 버튼을 클릭(토글)하여, 비즈니스 소개서나 제안서 등의 PDF 파일을 직접 업로드하면 AI가 해당 문서의 내용을 파싱하여 창작의 핵심 뼈대로 활용합니다.
*(입력창을 닫고 싶다면 열려 있는 버튼을 한 번 더 누르면 됩니다.)*

### Step 3. 분위기(Vibe) 및 테마 설정

1. **브랜드 분위기 선택**: 'AI 자동 추천'을 기본값으로 하되, 비즈니스 성격에 맞는 톤앤매너를 직접 지정할 수 있습니다.
2. **웹사이트 레이아웃 테마**: CreaiBox에서 제공하는 다양한 템플릿(비즈니스 스탠다드 등) 중 하나를 고르거나 AI 자동 매핑에 맡깁니다.

### Step 4. 동의 및 창작 실행

1. **[AI 에이전트 창작 시작]** 버튼을 클릭합니다.
2. 팝업에서 저작권 보호 동의를 거친 뒤, 창작이 시작됩니다.
3. 수집된 다중 웹페이지 텍스트 + 참조 PDF/텍스트 내용을 모두 결합해 AI 프롬프트로 전송하며, 짧은 시간 내에 '나의 창작 히스토리'에 사이트가 완성되어 추가됩니다.

## 3. 백엔드 AI 엔진 아키텍처 (`/api/studio/ai-magic-builder`)

이번에 개편된 다중 참조 기반 백엔드 엔진의 핵심 처리 과정입니다.

1. **메타 데이터 및 기초 텍스트 다중 수집**:
   입력받은 최대 3개의 URL을 비동기(`Promise.all`)로 동시 접근하여, 각 URL의 OpenGraph(OG) 태그 및 HTML 본문을 긁어와 `combinedExtraContent`로 병합합니다.
2. **참조 자료 파싱 (`pdf-parse`)**:
   `FormData`로 전달받은 첨부 파일(PDF)이 있을 경우 `pdf-parse` 모듈을 통해 텍스트로 변환하고 `extractedReference`로 담습니다.
3. **거대 컨텍스트 프롬프트 합성 및 Gemini 가동**:
   병합된 다중 URL 텍스트와 참조 자료 텍스트를 모두 `[추가 참조 자료]` 섹션으로 합성하여 Gemini 3.5 Flash Lite 엔진에 주입합니다.
4. **JSON 레이아웃 합성 및 DB 저장**:
   AI가 반환한 Tailwind HTML 섹션 리스트를 `site_sections`에 저장하며, 이미지 에셋(R2 변환) 등도 최적화하여 함께 적재합니다.

## 4. 향후 Apify를 활용한 딥-스크래핑(Deep-Scraping) 고도화 방안

현재 방식(서버사이드 단일 Fetch + AI 상상력)은 가장 빠르고 저렴하지만, 인스타그램이나 틱톡의 최근 피드 이미지와 상세 텍스트를 100% 긁어오지는 못한다는 한계가 있습니다. 이를 해결하기 위해 향후 **Apify(에이피파이) API**를 연동할 계획입니다.

### Apify란?

세계 최대 기계학습 웹 스크래핑 마켓플레이스이자 API 플랫폼입니다. 직접 크롤링 서버를 구축하지 않아도, 수백만 개의 가정용 IP(Residential Proxy)와 스텔스(Stealth) 기술이 적용된 크롬 브라우저를 클라우드에서 대신 띄워줍니다.

### CreaiBox 적용 시나리오 (v2 고도화)

1. **Apify API 호출**: 사용자가 인스타그램 주소를 넣으면, 백엔드는 즉시 Apify의 `Instagram Profile Scraper` Actor를 API로 호출합니다.
2. **리얼 데이터 확보**: 단 몇 초 만에 타겟 인스타그램의 최신 게시물 이미지 10장, 본문 텍스트 등의 정형화된 JSON 데이터를 받아옵니다.
3. **Gemini AI + 100% 실데이터 결합**: Apify가 긁어온 완벽한 실제 데이터를 Gemini에게 전달합니다. AI는 상상하는 비중을 줄이고, 실제 인스타그램 피드의 멋진 사진과 텍스트를 그대로 활용한 고퀄리티 홈페이지를 조립해 냅니다.

> **💡 전략적 이점**: Apify 연동 시 프론트엔드 UI를 전혀 수정할 필요 없이, 백엔드(`/api/studio/ai-magic-builder/route.ts`) 내부의 데이터 수집부 코드만 교체하면 되므로 유연하고 신속하게 업그레이드가 가능합니다.
