# Gmail & Resend 커스텀 도메인 이메일 연동 가이드 (발신 및 답장 설정)

**작성일**: 2026년 8월 11일
**목적**: Resend를 통해 개인 Gmail로 포워딩(수신)된 회사 도메인 이메일(`contact@creaibox.com` 등)을, 발신할 때도 회사 도메인 이름으로 보낼 수 있도록 세팅하는 매뉴얼.

---

## 1. 개요 및 주의사항

- 본 세팅은 대표님이나 내부 핵심 관리자 개인의 Gmail 계정에서 회사 공식 이메일을 발송하기 위한 'SMTP 우회 연동' 방법입니다.
- 🚨 **보안 경고**: 고객이나 외부 웹 파트너에게 절대 **Resend API 키**를 공유해서는 안 됩니다. 일반 유저는 수신(포워딩) 전용으로만 사용해야 하며, 발신이 필요하면 Google Workspace 등 유료 호스팅을 직접 결제하도록 안내해야 합니다.

---

## 2. Gmail '보낸사람(발신자)' 추가 세팅 방법

1. **Gmail 설정 진입**: 우측 상단 톱니바퀴 아이콘 ➡️ **[모든 설정 보기]**
2. **[계정 및 가져오기]** 탭 클릭
3. **'다른 주소에서 메일 보내기'** 섹션에서 **[다른 이메일 주소 추가]** 클릭
4. **1단계 팝업창 (발신자 정보 입력)**
   - **이름**: 메일 수신자에게 보여질 이름 (예: `CreAibox` 또는 `CreAibox 고객센터`)
   - **이메일 주소**: 사용할 회사 도메인 메일 (예: `contact@creaibox.com`)
   - **별칭으로 처리**: **체크 해제** (권장)
   - [다음 단계] 클릭
5. **2단계 팝업창 (SMTP 서버 인증)**
   - **SMTP 서버**: `smtp.resend.com`
   - **포트**: `465` (또는 `587`)
   - **사용자 이름**: `resend`
     > ⚠️ **매우 중요**: 이메일 주소가 무엇이든 상관없이 무조건 영어 소문자로 `resend` 라고만 입력해야 합니다!
     >
   - **비밀번호**: Resend 대시보드에서 발급받은 **API 키** (`re_...` 로 시작하는 전체 문자열)
   - 보안 연결(SSL) 선택 후 **[계정 추가]** 클릭
6. **인증 확인**: Gmail로 날아온 구글 인증 코드 숫자를 입력하면 연동이 완료됩니다.

---

## 3. [필수] 받은 주소로 자동 답장하게 만들기

포워딩된 메일에 무심코 답장했을 때 개인 Gmail 주소가 노출되는 것을 방지하기 위한 필수 설정입니다.

1. Gmail 설정 ➡️ **[계정 및 가져오기]** 탭
2. **'다른 주소에서 메일 보내기'** 섹션 바로 아래 **'메일 답장 시:'** 항목 확인
3. **🔘 메일을 받은 주소에서 답장하기** (Reply from the same address the message was sent to) 옵션 선택
4. 설정이 즉시 자동 저장됩니다.

---

## 4. ⚠️ 포워딩 메일 답장 시 치명적 주의사항 (수동 선택)

위 3번 설정을 하더라도, Resend가 중간에 메일을 '전달(Forward)' 해준 경우 Gmail이 착각하여 `~@gmail.com`으로 답장을 시도할 수 있습니다.

- **해결책**: 메일에 [답장]을 누른 후, 받는 사람 주소 위쪽에 있는 **'보낸사람(From)' 텍스트 영역을 마우스로 클릭**하여 드롭다운 메뉴를 엽니다.
- 여기서 반드시 **`contact@creaibox.com` (또는 해당 부서 메일)**을 수동으로 선택한 뒤 발송해야 완벽하게 회사 도메인으로 발송됩니다.
