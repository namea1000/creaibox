## 2. 실전 사용 가이드 (HOW-TO)

### 2.1. 사이트 정밀 스캔 실행
1. 입력창에 진단하고자 하는 사이트 주소(예: `http://futuremind.kr` 또는 `https://sotongchaeum.com`)를 입력합니다.
2. **`[ 🔍 1초 AI 정밀 진단 시작 ]`** 버튼을 클릭합니다.
3. 1초 내에 분석이 완료되며 종합 건강 등급(S, A, B, C, D, F)과 5대 영역 리포트가 화면에 표시됩니다.

### 2.2. 진단 보고서 확인 포인트
- **개발 엔진 식별**: 사이트가 어떤 빌더나 프로그램(피그마, 아임웹, 워드프레스 등)으로 만들어졌는지 확인합니다.
- **프레임셋 고정 포워딩 경고**: 도메인 포워딩 설정 오류로 인해 주소창이 고정되어 있는지 붉은색 경고 박스로 확인합니다.
- **1:1 초격차 비교표**: CreaiBox로 이관했을 때 얻을 수 있는 속도, SEO, 도메인 연결 혜택을 비교표로 확인합니다.

### 2.3. CreaiBox 정식 사이트 진단 시 동작
- 이미 CreaiBox에서 배포된 사이트(`*.creaibox.com`)를 입력하면 자동으로 **`Next.js React (CreaiBox 정식 초고속 웹)`**으로 감지되며, Vercel Edge 인프라 및 모바일 최적화 상태가 정상 표기됩니다.
- 우측 상단에는 불필요한 이관 버튼 대신 **`[ 🚀 CreaiBox 정식 라이브 사이트 관리하기 ]`** 버튼이 활성화되어 스튜디오 설정으로 즉시 이동할 수 있습니다.

### 2.4. 원클릭 현대화 이관 시작
- 외부 구형 사이트의 경우 보고서의 **`[ 🚀 이 사이트 CreaiBox로 1초 이관하기 ]`** 버튼을 클릭하면, 분석된 원본 사이트 정보가 `기존 홈페이지 AI 이관` 스튜디오로 자동 전달되어 즉시 복제 및 엣지 현대화 작업이 시작됩니다.

## 3. 자주 묻는 질문 (FAQ)

**Q. 비로그인 상태에서도 진단이 가능한가요?**
> A. 네! 비로그인 사용자도 사이트 정밀 진단과 비교표를 자유롭게 조회할 수 있습니다. 단, 진단 보고서를 DB에 영구 보관하고 이전 히스토리를 재열람하려면 로그인이 필요합니다.

**Q. CreaiBox 사이트인데 파비콘이나 서치콘솔이 '미등록'으로 떠요. 왜 그런가요?**
> A. CreaiBox는 **1대 규칙(Strict Zero Fake Data)**에 따라 실제 사이트의 HTML 소스 코드에 물리적으로 존재하는 태그만을 100% 솔직하게 검사합니다. 고객사 전용 파비콘이나 서치콘솔 소유권 인증키는 스튜디오 `홈페이지 설정` 탭에서 직접 등록해 주셔야 검색엔진에 정상 반영되므로, 미등록 상태일 경우 솔직하게 안내해 드립니다.

**Q. 브랜드 커스텀 이메일은 어떻게 사용하나요?**
> A. 브랜드 커스텀 이메일은 사이트 필수 건강 점수와 무관한 **무료 부가 혜택**입니다. 필요 시 스튜디오를 통해 `contact@도메인` 형식의 무료 포워딩을 언제든 신청하여 대표님 개인 메일함으로 연동하실 수 있습니다.

**Q. 프레임셋 포워딩 경고가 떴는데 어떻게 해결하나요?**
> A. CreaiBox의 도메인 연결(CNAME / A레코드 정석 바인딩)을 이용하거나, CreaiBox AI 이관을 통해 최신 Next.js 엣지 아키텍처로 사이트를 마이그레이션하면 즉시 해결됩니다.
