## 2. 실전 사용 가이드 (HOW-TO)

### 2.1. 사이트 정밀 스캔 실행
1. 입력창에 진단하고자 하는 사이트 주소(예: `http://futuremind.kr` 또는 `https://sotongchaeum.com`)를 입력합니다.
2. **`[ 🔍 1초 AI 정밀 진단 시작 ]`** 버튼을 클릭합니다.
3. 1초 내에 분석이 완료되며 종합 건강 등급(S, A, B, C, D, F)과 5대 영역 리포트가 화면에 표시됩니다.

### 2.2. 진단 보고서 확인 포인트
- **개발 엔진 식별**: 사이트가 어떤 빌더나 프로그램(피그마, 아임웹, 워드프레스 등)으로 만들어졌는지 확인합니다.
- **프레임셋 고정 포워딩 경고**: 도메인 포워딩 설정 오류로 인해 주소창이 고정되어 있는지 붉은색 경고 박스로 확인합니다.
- **1:1 초격차 비교표**: CreaiBox로 이관했을 때 얻을 수 있는 속도, SEO, 도메인 연결 혜택을 비교표로 확인합니다.

### 2.3. 원클릭 현대화 이관 시작
- 보고서 하단의 **`[ 🚀 이 사이트 CreaiBox로 1초 이관하기 ]`** 버튼을 클릭하면, 분석된 원본 사이트 정보가 `기존 홈페이지 AI 이관` 스튜디오로 자동 전달되어 즉시 복제 및 엣지 현대화 작업이 시작됩니다.

## 3. 자주 묻는 질문 (FAQ)

**Q. 비로그인 상태에서도 진단이 가능한가요?**
> A. 네! 비로그인 사용자도 사이트 정밀 진단과 비교표를 자유롭게 조회할 수 있습니다. 단, 진단 보고서를 DB에 영구 보관하고 이전 히스토리를 재열람하려면 로그인이 필요합니다.

**Q. 프레임셋 포워딩 경고가 떴는데 어떻게 해결하나요?**
> A. CreaiBox의 도메인 연결(CNAME / A레코드 정석 바인딩)을 이용하거나, CreaiBox AI 이관을 통해 최신 Next.js 엣지 아키텍처로 사이트를 마이그레이션하면 즉시 해결됩니다.
