# 📄 네이버 로그인 검수용 CreaiBox 서비스 소개서 PPT 텍스트 가이드

본 문서는 네이버 아이디로 로그인(네아로) 검수 승인을 위해 제출할 **CreaiBox 서비스 소개서 PPT/PDF 자료 작성용 표준 텍스트 스크립트**입니다. 슬라이드별로 캡처 이미지와 함께 아래 텍스트를 그대로 복사하여 붙여넣으시면 됩니다.

- **메인 타이틀**: CreaiBox (크리에이박스) AI 콘텐츠 포털 서비스 소개서
- **서브 타이틀**: 네이버 아이디로 로그인 검수 제출용 서비스 소명 자료

## 📌 [Slide 1] 메인 랜딩페이지 (`https://creaibox.com`)
- **슬라이드 제목**: 1. 메인 포털 홈 (Main Landing Page)
- **화면 캡처 설명**: 메인 홈 전체 화면 (히어로 비주얼 + 퀵 메뉴 바 + 실시간 키워드 바)
- **텍스트 설명**:
  - **주요 기능**: CreaiBox AI 통합 검색 바, 7대 스튜디오 퀵 메뉴 바, 실시간 급상승 키워드 & 뉴스 롤링 바, 포트폴리오 및 블로그 실시간 게시글 모음.
  - **서비스 특징**: 비로그인 상태에서도 모든 서비스 메뉴와 UI 구조를 자유롭게 둘러볼 수 있으며, 데이터 저장 및 AI 글쓰기 시 네이버 간편 로그인을 연결합니다.

## 📌 [Slide 10] 네이버 로그인 연동 절차 (OAuth 2.0 Auth Flow)
- **슬라이드 제목**: 10. 네이버 아이디로 로그인 동의 및 회원가입 인증 절차
- **화면 캡처 설명**: 
  - (왼쪽) 로그인 모달 팝업 화면
  - (중앙) 네이버 정보 제공 동의 팝업 화면 (`[동의하기]` 버튼)
  - (오른쪽) 로그인 완료된 CreaiBox 마이페이지/메인 화면
- **텍스트 설명**:
  - **로그인 방식**: 네이버 아이디로 로그인(Naver OAuth 2.0) 간편 인증 적용.
  - **수집 항목**: 이름, 이메일 주소, 닉네임 (최소한의 식별 정보만 수집).
  - **로그인 후 혜택**: 작성한 블로그 원고 자동 저장, 생성한 디자인 에셋 보관 및 커스텀 홈페이지 관리 기능 제공.
