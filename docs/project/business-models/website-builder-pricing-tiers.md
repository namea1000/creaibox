# CreaiBox 홈페이지 빌더 단계별 가격 정책 (Pricing Strategy)

이 문서는 CreaiBox의 "1페이지 랜딩부터 거대 기업형 사이트까지" 고객을 자연스럽게 유도하고 락인(Lock-in)하는 3단계 요금제 전략을 정의합니다.

## 💡 요금제 설계 철학 (Good-Better-Best)
- 진입 장벽을 파격적으로 낮춰(월 1만 원 미만) 일단 **고객을 무조건 우리 플랫폼에 가두는 것**이 핵심입니다.
- 일단 도메인이 연결되고 트래픽이 발생하기 시작하면, 고객은 사업 확장에 따라 자연스럽게 상위 요금제로 결제액을 올리게 됩니다.

---

## 🟢 Phase 1: 랜딩 요금제 (Lite / Starter)
**"명함 대신 뿌릴 수 있는 가장 세련된 1장짜리 사이트"**

* **목표 가격**: **월 9,900원** (약 1만 원)
* **타겟 고객**: 스타트업 사전예약(커밍순), 프리랜서 포트폴리오, 식당/카페 소개, 오프라인 이벤트 홍보, 개인 퍼스널 브랜딩
* **주요 제공 기능 및 서비스**:
  1. **AI 자동 생성**: 사용자가 텍스트 몇 줄만 넣으면 고품질 1페이지(One-pager) 랜딩페이지 즉시 생성
  2. **프리미엄 템플릿**: 최고급 글로벌 템플릿(Webflow/Framer 급) 무제한 선택 및 변경
  3. **초고속 웹 호스팅**: 글로벌 최고 수준의 Vercel CDN 무료 호스팅 서버 제공 (트래픽 무제한)
  4. **개인 도메인 연결**: 고객이 소유한 외부 도메인(`www.my-shop.com`) 무료 연결 지원
  5. **CreaiBox 블로그 & 글쓰기 기능 (기본 탑재)**: 랜딩페이지라도 원할 경우 `/blog` 게시판을 무료로 열어주며, CreaiBox 스튜디오의 강력한 AI 글쓰기 툴을 사용해 언제든 소식을 발행 가능
  6. **모바일 최적화**: PC, 태블릿, 모바일에 자동으로 반응하는 완벽한 반응형(Responsive) 웹
* **전략적 의미**: "도메인 유지비랑 호스팅 서버비만 내면, 수백만 원짜리 랜딩페이지 디자인이 공짜!"라는 프레임으로 넷플릭스 구독하듯 가볍게 결제하도록 유도합니다.

## 🔵 Phase 2: 프로 요금제 (Pro / Standard)
**"제대로 된 메뉴와 고객 DB가 필요한 진짜 기업용 홈페이지"**

* **목표 가격**: **월 19,000원** (약 2만 원)
* **타겟 고객**: 중소기업(SME), 학원, 병원, 법무/세무/노무법인, 인테리어/건축 에이전시, B2B 솔루션 기업
* **주요 제공 기능 및 서비스 (Phase 1 기능 모두 포함 + 알파)**:
  1. **다중 서브 페이지(Multi-page)**: 회사소개, 서비스 안내, 오시는 길 등 서브 메뉴 생성 가능 (예: 5~10장)
  2. **고객 DB 수집 (폼 연동)**: 방문자가 남긴 '상담 문의 / 견적 요청 / 예약 접수' 데이터를 CreaiBox 관리자 대시보드(DB)에 차곡차곡 저장
  3. **게시판 기능**: 공지사항, 갤러리(시공 사례 등), 자주 묻는 질문(FAQ) 게시판 제공
  4. **마케팅/SEO 기초**: 구글/네이버 검색엔진 최적화(SEO) 메타 태그 세밀 조정, 구글 애널리틱스(GA4) 원클릭 연동
  5. **(기본 제공)**: 커스텀 도메인, CreaiBox 블로그/AI 글쓰기 툴, 모바일 최적화 등 Phase 1 기능 모두 포함
* **전략적 의미**: 사업이 본격화되어 고객의 문의(DB)를 받아야 하거나, 포트폴리오를 계속 업데이트해야 하는 '진성 사업자'들을 위한 스탠다드 요금제입니다. DB가 당사에 쌓이기 시작하므로 이탈률이 급감합니다.

## 🟣 Phase 3: 엔터프라이즈/프리미엄 요금제 (Premium / Business)
**"결제, 회원관리, AI 자동화가 결합된 올인원 비즈니스 플랫폼"**

* **목표 가격**: **월 29,900원** (약 3만 원)
* **타겟 고객**: 적극적인 콘텐츠 마케팅을 하는 기업, 온라인 결제가 필요한 커머스/예약 서비스, 거대 미디어/매거진
* **주요 제공 기능 및 서비스 (Phase 2 기능 모두 포함 + 알파)**:
  1. **무제한 페이지 & 용량**: 수백 개의 게시글과 고화질 이미지를 올릴 수 있는 넉넉한 클라우드 스토리지
  2. **AI 오토 블로깅 (SEO 폭격)**: 챗GPT/Gemini가 매일 자동으로 업계 관련 전문 블로그 글을 써서 검색엔진 1페이지 노출을 유도하는 강력한 마케팅 기능
  3. **결제 및 회원 시스템 (옵션/확장)**: 포트원(PortOne) 연동을 통한 간단한 상품 결제, 회원가입 및 로그인 기능 제공 (CMS화)
  4. **커스텀 코드 삽입**: 개발자를 위한 `<head>` 및 `<body>` 태그 내 사용자 정의 스크립트(채널톡, 메타 픽셀 등 고급 트래킹) 삽입 권한
  5. **(기본 제공)**: 커스텀 도메인, CreaiBox 블로그/AI 글쓰기 툴, 모바일 최적화, 다중 서브페이지 등 하위 요금제 기능 모두 포함
* **전략적 의미**: 단순히 '보여주는' 홈페이지를 넘어, 웹사이트 자체가 영업사원 역할을 하고 돈을 벌어다 주는(마케팅 자동화) 플랫폼으로 격상됩니다. 3만 원이 절대 아깝지 않은 B2B 필수 솔루션으로 포지셔닝합니다.

## 🚀 Phase 4: 에이전시/파트너 요금제 (Agency / Expert) - *[제안]*
**"웹에이전시와 마케터들이 고객의 사이트를 찍어내는 B2B 대량 생산 기지"**

* **목표 가격**: **월 99,000원 ~ 149,000원** (또는 사이트당 도매가 할인 적용)
* **타겟 고객**: 웹디자인 외주 업체, 프리랜서 디자이너, 마케팅 대행사, 프랜차이즈 본사
* **주요 제공 기능 및 서비스**:
  1. **화이트 라벨링 (White-labeling)**: 관리자 대시보드 및 사이트 하단(Footer)에서 `CreaiBox` 로고와 브랜딩을 100% 제거하고, 에이전시 본인들의 로고로 둔갑시킬 수 있는 기능
  2. **다중 사이트 통합 관리 (Workspace)**: 하나의 계정에서 수십~수백 개의 고객사(클라이언트) 홈페이지를 동시에 관리하고 배포하는 대시보드
  3. **고객사 권한 분리 (Client Handoff)**: 에이전시가 사이트를 다 만들고 난 뒤, 고객사에게 '글쓰기/수정 권한'만 있는 제한된 관리자 계정을 발급해 주는 기능
  4. **코드 추출 (Export Code)**: 생성된 사이트의 순수 프론트엔드 코드(React/HTML 등)를 압축파일로 다운로드 받아 독립 서버에 구축할 수 있는 권한
* **전략적 의미**: SaaS 기업이 폭발적으로 매출을 스케일업(Scale-up)하는 가장 확실한 방법입니다. B2B 파트너들이 CreaiBox를 이용해 돈을 벌게 해주면, 그들이 알아서 수백 개의 사이트를 우리 플랫폼 위에서 찍어내는 **거대한 '도매(B2B) 생태계'**가 완성됩니다. Webflow와 Shopify가 조 단위 기업이 된 핵심 비결이 바로 이 에이전시 요금제입니다.
