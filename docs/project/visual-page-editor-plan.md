# 🖊️ 비주얼 페이지 에디터 (Visual Page Editor) 구현 계획

> 작성일: 2026-08-12  
> 상태: 📋 기획 완료 / 개발 대기 중

**목표**: "페이지 & 글 관리"의 "레이아웃 편집하기" 버튼을 눌렀을 때, AI 홈페이지 빌더가 아닌 **전용 비주얼 페이지 에디터**로 이동하는 기능 구현.  
repaint.com의 "편집 모드" + 워드프레스 페이지 에디터의 장점을 결합한 인라인 WYSIWYG 편집기.

---

## 📌 배경 및 현재 문제

- `posts/page.tsx`의 "레이아웃 편집하기" 버튼이 현재 `/studio/client-site-builder/builder`(AI 홈페이지 빌더)로 이동 → **잘못된 경로** (수정 필요)
- 기존 `SectionEditor.tsx`는 JSON 필드 폼 편집 방식 → 불편하고 직관적이지 않음
- 사이트 섹션 HTML은 `site_sections.content_data.html`에 Tailwind HTML로 저장됨
- 서브페이지 섹션타입: `subpage_*` (DB에 저장되나 현재 UI에 미노출)

### 참조 레퍼런스
- [repaint.com](https://app.repaint.com/) — 화면 하단 "편집 모드" 버튼으로 텍스트 직접 수정
- WordPress 페이지 에디터 — 블록 추가, 텍스트/이미지 수정, 새 페이지 생성

---

## 🏗️ 구현 방향: 인라인 WYSIWYG 비주얼 에디터

repaint.com처럼 **실제 렌더링된 페이지 위에서 직접 편집**하는 방식으로 구현한다.

```
[Studio] 페이지 에디터 라우트
  ├─ 1. 페이지 목록 UI (메인 + 서브페이지 모두 DB 동기화)
  ├─ 2. 각 페이지 카드에 "✏️ 페이지 직접 편집" 버튼 추가
  └─ 3. /studio/client-site-builder/page-editor/[slug] 에디터 화면
       ├─ 좌측 패널: 섹션 블록 목록 + 블록 템플릿 추가
       ├─ 우측 메인: 실제 페이지 미리보기 (contentEditable 인라인 편집)
       └─ 상단바: 저장, 미리보기, 발행 버튼
```

---

## 🔧 핵심 기술 아키텍처

### 편집 방식: 3-레이어 구조

| 레이어 | 역할 |
|:---|:---|
| Layer 1 (미리보기 렌더러) | 실제 `site_sections.content_data.html`을 Tailwind로 렌더링 |
| Layer 2 (오버레이 에디터) | hover 시 편집 가능한 블록 하이라이트 표시 |
| Layer 3 (패널 에디터) | 좌측 패널에서 텍스트/이미지 필드를 직접 편집 |

### 데이터 흐름
```
DB (site_sections.content_data)
  → React 상태로 로드
  → 편집 패널에서 수정
  → 실시간 미리보기 갱신
  → 저장 버튼으로 DB 업데이트
```

## 📋 구현 범위 (Phase 1 — 즉시 구현)

### ✅ 포함 기능

| 기능 | 설명 |
|:---|:---|
| 텍스트 편집 | `contentEditable` 방식으로 h1, p, span 등 더블클릭 직접 수정 |
| 이미지 교체 | 이미지 클릭 → 업로드 버튼 팝오버 표시 → Supabase Storage 업로드 |
| 블록 추가 | 좌측 패널에서 블록 템플릿(히어로, 카드그리드, CTA, 갤러리 등) 클릭하여 추가 |
| 블록 삭제 | 섹션 패널에서 삭제 버튼 클릭 |
| 실시간 저장 | 저장 버튼으로 `site_sections` DB 업데이트 |
| 페이지 목록 동적화 | 하드코딩된 sitePages → DB의 `site_sections` 기반 동적 렌더링 (서브페이지 포함) |

### 🔜 Phase 2 (향후)
- 드래그&드롭 블록 순서 변경
- 블록 배경 색상/그라디언트 변경
- 폰트 크기/색상 인라인 커스텀

## ✅ 검증 계획

1. `npx tsc --noEmit` — 타입 에러 없음 확인
2. 로컬 dev 서버에서 페이지 에디터 진입 → 섹션 텍스트 수정 → 저장 → 라이브 사이트 새로고침으로 반영 확인
3. 이미지 업로드 후 미리보기 즉시 갱신 확인
4. 블록 템플릿 추가 후 저장 확인
5. 서브페이지도 목록에 표시되는지 확인
