# 🏛️ CreaiBox Master Documentation Index (4-Pillar Architecture)

CreaiBox 프로젝트의 모든 기능 및 서비스는 **디아탁시스(Diátaxis) 프레임워크 기반의 4대/2대 마스터 문서 체계**에 의해 영구 관리됩니다.

---

## 📌 4대 마스터 문서 체계 (4-Pillar Structure)
1. 🔴 **아키텍처 기술 명세서 (`docs/arch/`)**: WHY & WHAT (설계 배경, Mermaid 시퀀스 및 데이터 흐름도)
2. 🔵 **서비스 실무 매뉴얼 (`docs/project/manual/`)**: HOW (화면 조작법, 1분 셋업, 금지 패턴, FAQ)
3. 🟡 **데이터베이스 스키마 명세서 (`docs/database/`)**: SCHEMA (테이블 명세표, 컬럼 설명, ERD, RLS 보안 정책)
4. 🟢 **데이터베이스 SQL 실행 스크립트 (`docs/database/sql/`)**: PURE SQL (Supabase에서 즉시 실행 가능한 순수 DDL/트리거)
