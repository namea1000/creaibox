# 외부 이미지 API 프로바이더 분석 및 연동 전략 명세서

이 문서는 CreAibox AI 스튜디오(홈페이지 자동 생성, 비디오 생성 등)에서 고품질 이미지 에셋을 확보하기 위해 검토 가능한 외부 이미지 소스 플랫폼들의 스펙, 비용, 장단점 및 연동 전략(BM)을 정리한 아키텍처 문서입니다.

---

## 1. 🟢 즉시 도입 가능한 무료 고품질 소스 (Free & High Quality)

AI 자동 생성 파이프라인에서 기본(Default) 소스로 활용하기 가장 적합한 플랫폼들입니다.

### 1-1. Unsplash (현재 적용 중 - 1순위 Proxy)
- **사이트**: [https://unsplash.com/developers](https://unsplash.com/developers)
- **비용**: 무료 (상업적 이용 가능)
- **API 무료 한도**: 시간당 50회 (Demo 계정 기준) / 승인 시 시간당 5,000회 (Production)
- **장점**: 압도적으로 세련되고 현대적인 고화질 감성 사진 보유. 트렌디한 웹사이트 디자인에 가장 잘 어울림.
- **단점**: 무료 API 호출 한도(50회/시간)가 매우 빡빡함. 웹 빌더 성격의 서비스는 Production 승인을 받기가 까다로움.

### 1-2. Pexels (픽셀스)
- **사이트**: [https://www.pexels.com/api/](https://www.pexels.com/api/)
- **비용**: 무료 (상업적 이용 가능)
- **API 무료 한도**: 시간당 200회 / 월 20,000회
- **장점**: Unsplash에 버금가는 고화질 감성 사진 및 **무료 영상(Video)** 소스까지 API로 제공. 무료 한도가 Unsplash보다 4배 넉넉함.
- **단점**: 검색 결과의 정확도가 가끔 떨어질 때가 있음.

### 1-3. Pixabay (픽사베이)
- **사이트**: [https://pixabay.com/api/docs/](https://pixabay.com/api/docs/)
- **비용**: 무료 (상업적 이용 가능)
- **API 무료 한도**: **시간당 5,000회** (가장 넉넉함)
- **장점**: 사진뿐만 아니라 **일러스트레이션, 벡터 이미지, 아이콘** 등 방대한 자료 보유. 한도가 넉넉하여 대용량 트래픽 처리에 매우 유리함.
- **단점**: 일부 이미지들이 다소 올드한 "전형적인 스톡 사진" 느낌을 줄 수 있음.

## 2. 🔴 프리미엄 유료 스톡 (Premium Paid Stock)

압도적인 상업 퀄리티를 자랑하지만, 장당 결제가 필요하여 AI 무제한 자동 생성에는 적합하지 않고 **CreAibox Pro 요금제(유료 크레딧 모델)**용으로 도입해야 하는 플랫폼입니다.

### 2-1. Adobe Stock (어도비 스톡)
- **사이트**: [https://developer.adobe.com/stock/apis/](https://developer.adobe.com/stock/apis/)
- **비용**: 유료 (크레딧/구독형 결제, 장당 수천 원 ~ 수만 원)
- **장점**: 세계 최고 수준의 고퀄리티 에셋, 완벽한 저작권 클리어런스, AI 에셋 통합.
- **단점**: 자동 생성용 플레이스홀더로 사용 불가. (워터마크 없는 원본은 결제 필수)

### 2-2. Shutterstock (셔터스톡)
- **사이트**: [https://developers.shutterstock.com/](https://developers.shutterstock.com/)
- **비용**: 유료 (크레딧/구독형 결제)
- **장점**: 전 세계에서 가장 방대한 프리미엄 사진, 벡터, 영상 라이브러리 보유.
- **단점**: Adobe Stock과 마찬가지로 API 호출 및 라이선스 발급 비용이 매우 비쌈.

## 3. 🟡 폴백(Fallback) 및 더미 템플릿 소스

무료 API 한도를 모두 소진했거나 오류가 났을 때 화면 깨짐(엑박)을 방어하기 위한 최후의 수단들입니다.

### 3-1. LoremFlickr (현재 적용 중 - 2순위 Fallback)
- **사이트**: [https://loremflickr.com/](https://loremflickr.com/)
- **비용**: 완전 무료
- **API 무료 한도**: **무제한 (API 키 불필요)**
- **장점**: API 키 가입 없이 URL(예: `loremflickr.com/800/600/golf`)만으로 즉시 동적 키워드 이미지 호출 가능.
- **단점**: Flickr(플리커) 내의 일반 유저 사진을 랜덤으로 가져오므로, 가끔 퀄리티가 낮거나 엉뚱한 이미지가 나올 확률이 높음.

### 3-2. Placehold.co (현재 적용 중 - 3순위 최종 방어)
- **사이트**: [https://placehold.co/](https://placehold.co/)
- **비용**: 완전 무료
- **API 무료 한도**: 무제한
- **장점**: 초고속 렌더링, 색상 및 텍스트 지정 가능, SVG 반환으로 용량 최소화.
- **단점**: 실제 사진이 아닌 단순 단색 블록(Color Block) 형태만 제공.

## 💡 CreAibox 추천 통합 아키텍처 (황금 밸런스 5중 구조)

최고의 '품질'과 '한도(안정성)' 사이의 딜레마를 해결하기 위해, 평소에는 무조건 최고 퀄리티를 유지하면서 유저가 몰릴 때만 넉넉한 한도로 방어하는 **황금 밸런스 5중 구조**를 권장합니다.

1. **1순위 (Unsplash API)**: 압도적인 1위 품질 (명품 에셋). 시간당 50장까지는 무조건 최고의 감성 퀄리티로 뽑아냅니다.
2. **2순위 (Pexels API)**: Unsplash 한도 50장을 다 쓰면, 품질이 거의 흡사한 Pexels로 스무스하게 넘어갑니다. (시간당 200장 방어)
3. **3순위 (Pixabay API)**: 폭발적인 사용량으로 시간당 250장을 모두 소진하면, 비로소 무제한급(5,000장/시간)인 Pixabay가 작동하여 트래픽을 방어합니다.
4. **4순위 (LoremFlickr / Placehold.co)**: 위 3개의 API 네트워크가 모두 장애가 날 경우 발동하는 최후의 무과금 폴백(Fallback) 안전망.
5. **[BM 확장] Premium API (Adobe/Shutter)**: 향후 유료 결제 유저(Pro Plan) 전용으로, 생성된 홈페이지의 에셋을 프리미엄 에셋으로 일괄 교체해 주는 고수익 비즈니스 모델로 연동.
